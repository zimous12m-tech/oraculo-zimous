# 🔮 Oráculo Causal Supremo — Teoria de Zimous

> **"A avaliação exploratória da posição, inércia, recursos e alavancagem humana."**

O **Oráculo Causal Supremo** é uma aplicação web interativa que operacionaliza a Teoria de Zimous. Permite aos utilizadores fazerem um diagnóstico longitudinal do seu estado atual (contexto, forças do rio, recursos e eficiência de ação) e acompanhar a sua evolução ao longo do tempo.

### 🚀 Aceder à Aplicação
A aplicação está online, pronta a usar no PC ou no telemóvel:
👉 **[CLIQUE AQUI PARA ABRIR O ORÁCULO](https://zimous12m-tech.github.io/oraculo-zimous/)**

### 🧠 Funcionalidades Principais
- **Diagnóstico Causal:** Calcula a Ação Moduladora (AM), Dinâmica Dominante (DD) e Eficiência da Ação (EA).
- **Perfis de Contexto:** Ajusta os pesos do cálculo para momentos de Crise, Elite, Projeto ou Geral.
- **Histórico Longitudinal:** Guarda os testes de cada sujeito no dispositivo e mostra a evolução através de um gráfico interativo.
- **Exportação:** Descarrega relatórios em JSON, imprime em PDF ou exporta um resumo em Markdown pronto para ser lido por uma Inteligência Artificial.
- **Privacidade:** Os dados são guardados localmente no navegador (LocalStorage). Nada é enviado para servidores externos.

### 🛠️ Tecnologias
- HTML5, CSS3 e JavaScript Vanilla (Zero dependências de frameworks).
- Design focado em Mobile-First e Dark Mode.
- Gráficos interativos desenhados em SVG puro.
